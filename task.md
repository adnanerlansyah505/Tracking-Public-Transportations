# MVP Scope

## Authentication
- Login
- Register (such as Full Name, Email, Password, Confirm Password, City, Country, Birth Date, Gender, etc.)
- Logout
- Forgot Password

## Dashboard
- The most active driver (can be filter by week, month, or year)
- The most active passenger (can be filter by week, month, or year)
- The total driver 
- The total passenger
- The most frequently tracked locations

# Profile
- Update the profile of users such name, birth date, password, etc.
- Update the data of the driver such as type of public transport vehicle (whether it's bus or public minivan.

## Courses
- CRUD (which has data of title, description, price, and the score of graduation standards)
- CRUD modules within the course (this module for user learning the material).
- 

## Classroom
- CRUD of the classroom
- Filter for the classroom (by search or program)
- Classroom can create assignment (for link, file, and form type)
- Classroom can assigned the courses
- Overview of the classroom
- Single-view display for class details, without needing to be redirected to another page

## Review Assignment
- Can review the assignment of each classroom
- Can assess the assignment of each student from the assignment of the classroom
- Can see the assignment of the student whether it's from file, link, or form.
- Apply the pagination of to limit the display of data on students who have submitted their assignments.

## Form
- CRUD feature 
- CRUD for the questions of the form
- Preview for the admin or mentor to see the assignment of the student

## Raport
- To see the assessment of the assignments of each classroom from the student
- Can download the raport

## Certification
- To see the certificate if the user has already passed the graduation criteria of the classroom
- Can download the certificate
