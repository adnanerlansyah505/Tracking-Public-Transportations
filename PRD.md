# Tracking Public Transporation

## Product Goal
Tracks every public transport vehicle registered in the app. Users can locate the nearest public transport vehicles by enabling location services, while drivers can activate their own location to allow passengers to track them in real-time.

## Target Users
- Public
- Student
- Employee

## Core Features
- Authentication (like to check the users whether they're admin, driver, or passenger (default))
- Profile
- Homepage with an interface similar to Google Maps 
- Searching Public Transporation
- Detecting Public Transporation
- Chat between the driver & passenger
- Rating for the driver
- Driver

# Technologies 
- NestJS (latest version as the Backend)
- React Native (latest version as the Frontend, the goal is to enable cross-platform).
- TailwindCSS
- UI Library that possible and easy to use
- Zod for the validation form
